# Contributing to Realistic Orbital Launch Simulation

First off, thank you for considering contributing to the Realistic Orbital Launch Simulation! It's people like you that make it a great tool for aerospace enthusiasts.

## Code of Conduct
By participating in this project, you are expected to uphold our Code of Conduct (Standard Contributor Covenant).

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub with:
* A clear, descriptive title.
* Steps to reproduce the bug.
* Expected behavior vs. actual behavior.

### Suggesting Enhancements
Enhancements can range from new physics features (e.g., aerodynamics improvements) to UI tweaks. Please submit an issue tagged as "enhancement".

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. Make your changes in a clear, logical structure.
3. Test your changes locally in the browser.
4. Issue that pull request!
